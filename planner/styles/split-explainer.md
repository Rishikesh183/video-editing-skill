# Style: split-explainer (from the creator's reference "edit2", analysed frame by frame)

- Layout mix: about half the video is a 50/50 split - analysis panel on top, creator in the bottom half
  (9:16) - alternating with full-screen creator. The split holds for a whole explanation (4-8 s), not a beat.
- Panel content: real screenshots (scorecards, broadcast frames) on a near-black grid, pushed in slowly; the
  important number is circled in red; callout pills appear one by one as each point is spoken: white pill
  with dark text for facts, a red pill for the key fact, a green arrow badge leading the first pill.
- Maths is written out step by step ("50 - 27.3 overs", "22.3 overs left", "Run rate 117 / 18 = 6.5").
- Typography: clean sans (Inter/Montserrat), sentence case, small-to-medium; colour only on the key value.
- Motion: pills pop in, screenshots ease in and drift, no flashy transitions; a sound on every new pill.
- Pacing: a new element every 1-1.5 s inside the panel while the creator explains.
- Building blocks: split (photo + callouts, or value + callouts), compare-bars and stat-hero for numbers,
  headline over the face for the hook.
- Do: show the evidence (screenshot), then annotate it. Don't: decorate with stage backdrops or props.
